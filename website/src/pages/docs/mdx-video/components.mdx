# Built-in Components

egaki includes visual components ported from [remocn](https://github.com/kapishdima/remocn).
All are available in MDX without imports.

## Fill

A full-frame layer like Remotion's `AbsoluteFill` but with better defaults.
Children stretch horizontally and center vertically.

```mdx
<Fill style={{ background: '#09090b' }}>
  <div style={{ fontSize: 72, color: 'white' }}>Centered content</div>
</Fill>
```

Prefer `<Fill>` over raw `<AbsoluteFill>` in egaki components.

## Background

Renders behind section content. Use for gradient backgrounds, images, or videos:

```mdx
<Background>
  <MeshGradientBg />
</Background>
```

## BlurReveal

Animated text reveal with a blur-to-sharp transition:

```mdx
<BlurReveal text="Hello World" />
```

## MeshGradientBg

Animated mesh gradient background:

```mdx
<Background>
  <MeshGradientBg />
</Background>
```

## MaskedSlideReveal

Text reveal with a sliding mask animation:

```mdx
<MaskedSlideReveal text="Sliding reveal" />
```

## StaggeredFadeUp

Children fade up one by one with staggered timing:

```mdx
<StaggeredFadeUp>
  <div>First</div>
  <div>Second</div>
  <div>Third</div>
</StaggeredFadeUp>
```

## TerminalSimulator

Animated terminal with typed-out commands:

```mdx
<TerminalSimulator
  commands={['npm install egaki', 'egaki image "hello" -o hello.png']}
/>
```

## GlassCodeBlock

Code block with frosted glass styling:

```mdx
<GlassCodeBlock
  code={'const x = 42'}
  language="typescript"
/>
```

## ShimmerSweep

A shimmer sweep effect over content:

```mdx
<ShimmerSweep>
  <div style={{ fontSize: 48 }}>Shimmering text</div>
</ShimmerSweep>
```

## SpringPopIn

Spring-based pop-in animation:

```mdx
<SpringPopIn>
  <div style={{ width: 200, height: 200, background: '#6366f1', borderRadius: 16 }} />
</SpringPopIn>
```

## AnimatedChart

Animated bar or line chart:

```mdx
<AnimatedChart
  data={[40, 70, 45, 90, 60]}
  type="bar"
/>
```

## Img and Video

Always use `<Img>` from `egaki/video` instead of raw `<img>`. The egaki version
uses `delayRender()` to prevent blank frames during export.

```mdx
<Fill>
  <Video src="/clip.mp4" muted loop objectFit="cover" />
</Fill>

<Img src="/photo.png" objectFit="cover" style={{ width: '100%', height: '100%' }} />
```

Use `objectFit="cover"` to fill the frame edge to edge, cropping excess content.
