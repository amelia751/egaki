## CLI generation

One command to generate images, videos, or speech. Provider keys or an egaki
subscription handle authentication.

```bash
egaki image "a watercolor fox reading a map" -o fox.png
egaki video "a paper boat drifting on a calm lake at sunrise" -o boat.mp4
egaki speech "Hello world" -o hello.mp3
```

## MDX video framework

Write video scenes in MDX. Each heading becomes a timed section. Animation
primitives like `Opacity`, `TranslateX`, and `Scale` handle motion. Export to
MP4 via in-browser WebCodecs rendering.

```mdx
---
fps: 30
bpm: 120
---

# Intro duration=3s

<TranslateX from={-140} to={0} duration={0.7 * FPS}>
  <div style={{ fontSize: 72, fontWeight: 900, color: 'white' }}>Hello</div>
</TranslateX>

# Scene Two duration=5s

<Opacity from={0} to={1} duration={1 * FPS}>
  <div style={{ fontSize: 48, color: '#818cf8' }}>Built with egaki</div>
</Opacity>
```
